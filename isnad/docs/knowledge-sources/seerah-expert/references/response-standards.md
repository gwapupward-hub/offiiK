# Response Standards

## Narrative Answer

Use the smallest useful structure:

### Main account

Tell the established sequence clearly.

### What is firmly established

Identify Qur'anic and authentic hadith anchors.

### Reported details and uncertainty

Label disputed, weak, or approximate material only when it affects understanding.

### Lessons

Separate explicit teachings from inferred moral or strategic lessons.

### Sources

List primary sources before later synthesis.

## Formal Historical Reconstruction

1. **Question and scope**
2. **Fixed evidence anchors**
3. **Reconstructed sequence**
4. **Material variants**
5. **Chronology and geography**
6. **Historical context**
7. **What cannot be established**
8. **Lessons and limits**
9. **References**

Use a table when dates, reports, or people require exact mapping.

## Report Audit

### Claim

Quote only the wording actually under review.

### Finding

Give the status label immediately.

### Earliest sources

Identify routes and source dependence.

### Evidence analysis

Explain chain, text, corroboration, and conflicts with stronger evidence.

### Corrected account

State the strongest defensible version.

### Confidence

Name what is established and what remains unresolved.

## Person Profile

Include only relevant fields:

- name and variants;
- lineage or affiliation;
- relationship to Prophet Muhammad ﷺ;
- chronology;
- established actions or reports;
- disputed identifications;
- later significance.

Avoid encyclopedia padding and unsourced praise or blame.

## Timeline Table

| Date or period | Event | Status | Primary evidence |

| ... | ... | ... | ... |

Mark calculations and conventional dates.

## Sensitive Controversy

1. State the precise allegation without sensational repetition.
2. Give the strongest source finding.
3. Explain disputed details and context.
4. Address the argument fairly.
5. State what the evidence does not permit.
6. Avoid collective blame and present-day incitement.

## Language

- Use plain English and define Arabic terms on first use.
- Write “Prophet Muhammad ﷺ” and respectful forms for the Companions.
- Use quotation marks only for verified wording.
- Do not narrate reconstructed dialogue as direct speech.
- Say “the report states” rather than endorsing an unverified claim.
- Avoid cinematic embellishment.
- Use “Allah knows best” when appropriate, not as a substitute for research.
